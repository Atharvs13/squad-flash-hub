# Our College Chronicle

Create a single-page responsive website for our college class page. The vibe should be medium-level fun and slightly cringe (student meme energy), but still clean enough that teachers would not hate it. Think Instagram-college-club style, not a corporate website.

Theme
- Colors: dark blue, white, purple, and a little neon pink for highlights.
- Font: modern rounded fonts (Poppins / Outfit / Montserrat).
- Add small emojis in headings (🔥 📸 🎓 🚀) but do not overuse them.
- Smooth scrolling, hover animations, fade-in sections, and a few playful stickers or doodles.

Hero / Banner Section
- Full-width banner with our uploaded class photo as the background.
- Add a dark overlay so text is readable.
- Heading: "Welcome to Our College Squad"
- Subheading: "Assignments, memories, reels, chaos, and attendance struggles — all in one place."
- Add two buttons:
  - View More Photos
  - Follow Our Instagram

About Section
- Short funny description: "We are a bunch of students trying to survive lectures, practicals, internal exams, and group projects while somehow making reels in between."

Photo Gallery
- Grid of 8–12 uploaded photos (use the uploaded photo, repeated/placeholder as needed since we only have one right now).
- Clicking View More Photos should open a lightbox/gallery page or modal with all photos.
- Add captions like: "Before viva", "After viva", "Lab legends", "Proxy attendance squad"

Instagram Reels Section
- Create a section titled "Latest Reels 🎬"
- Display Instagram-style reel cards (3–6 cards).
- Each card should contain: Thumbnail image, Reel title, Small view count, A Watch Reel button
- The button should redirect to our Instagram reel links.
Use placeholder links that can easily be replaced:
- https://instagram.com/ourcollegepage
- https://instagram.com/reel1
- https://instagram.com/reel2
- https://instagram.com/reel3

Social Section
Display icons and buttons for: Instagram, WhatsApp Group, Telegram Channel, YouTube (optional). All buttons should open external links in a new tab.

Memory Wall
Add a playful section with fake student quotes such as:
- "Attendance is temporary, memories are forever."

- "We came for the degree, stayed for the friends."

Footer
- "Made with caffeine, deadlines, and friendship."
- "© 2026 Our College Class Page"

Technical Requirements
- Fully responsive for mobile and desktop.
- Smooth animations.
- Gallery modal/lightbox.
- Buttons for Instagram and photo gallery.
- Easy to replace photos and links later.
- Do not make it too professional or too childish; keep it at a medium fun college level.
